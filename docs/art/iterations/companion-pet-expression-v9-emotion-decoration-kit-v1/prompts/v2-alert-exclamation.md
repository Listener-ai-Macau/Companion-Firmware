# V35 Alert Exclamation Decoration Source, Revision 2

Use the attached locked V9 Companion face only as the style reference. Generate
an art-source sheet for a three-beat alert-exclamation decoration component,
not a character portrait and not a UI warning badge.

Pure white background. Pure black crisp monochrome. Make exactly three clearly
separated, equally scaled poses from left to right, each one a compact friendly
exclamation mark for an unseen V9 face. Use a visibly wide rounded tapering
stem, not a thin vertical stroke: when scaled into a 24 by 34 pixel target box
the stem must remain balanced and at least two pixels thick. Use one detached
round dot. Pose one is short and low, pose two rises with the dot delayed, pose
three settles into a complete but restrained mark. It should communicate sudden
attention, not danger, anger, text typography or a generic UI alert.

Do not draw a face, eyes, eyebrows, mouth, cheeks, body, hands, ears, speech
bubble, text other than the single exclamation-mark symbol, label, grid, frame,
border, menu UI, sparkle, star, lightning bolt, battery icon, color, gray,
shadow or texture.

This is an animation-component source only. It will later be cropped into three
registered masks and composed above the unchanged locked V9 daily face.
