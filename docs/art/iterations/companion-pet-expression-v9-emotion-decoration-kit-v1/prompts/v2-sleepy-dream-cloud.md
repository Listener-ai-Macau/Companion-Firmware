# V35 Sleepy Dream Cloud Decoration Source, Revision 2

Use the attached locked V9 Companion face only as the style reference. Generate
an art-source sheet for a three-beat sleepy-dream-cloud decoration component,
not a character portrait, weather symbol or speech bubble.

Pure white background. Pure black crisp monochrome. Make exactly three clearly
separated, equally scaled poses from left to right, each one a small puffy
dream cloud with three rounded lobes and a deliberately open, light V9-like
outline that stays readable in a 42 by 27 pixel target box. Pose one is a
compact quiet cloud, pose two drifts one tiny step up-left and gains one small
trailing dream puff, pose three drifts one more tiny step and lets that puff
follow. The cloud must be the only sleep symbol; it must not contain a moon,
letter, Z, sparkle, star, rain, smoke, anger or speech-tail geometry.

Do not draw a face, eyes, eyebrows, mouth, cheeks, body, hands, ears, speech
bubble, text, letters, label, grid, frame, border, menu UI, color, gray,
shadow or texture.

This is an animation-component source only. It will later be cropped into three
registered masks and composed above the unchanged locked V9 sleepy face.
