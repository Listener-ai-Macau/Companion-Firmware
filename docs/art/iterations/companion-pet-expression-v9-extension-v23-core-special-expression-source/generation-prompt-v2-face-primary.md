# V23 Core Special Expression Source Prompt V2

Use only the locked V9 reference image recorded in
`generation-request-v2-face-primary.json`. Generate one clean monochrome source
pose at a time on a pure white background. The result is source art for
component extraction, not a runtime frame or a UI mockup. Preserve the V9 eye
silhouettes, eye pair spacing, single primary highlights, small sparkles and
nose exactly. Do not add text, UI, buttons, battery, plug, lightning,
microphone, waveform, menu icon, question, exclamation, heart or star.

The special state must be legible from the face alone. Menu uses composed inward
focus in the brows and a compact asymmetric thinking mouth. Recording uses
gentle centered attentive brows, a calm closed focus mouth and a subtle cheek
relationship. Charging uses relaxed raised brows, a small rounded content smile
and buoyant cheeks. No contextual accent is required or allowed to become the
reason the state is recognizable.

Every visible mark must be separable as a component and fit in a 200x200
export-safe face area. The source must support entry, one bounded in-state
motion and a causal exit through components only.
