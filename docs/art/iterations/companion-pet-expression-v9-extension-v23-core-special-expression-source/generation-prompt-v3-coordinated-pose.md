# V23 Core Special Expression Source Prompt V3

Use only the locked V9 reference image recorded in
`generation-request-v3-coordinated-pose.json`. Generate one clean monochrome
source pose at a time on a pure white background. The result is source art for
component extraction, not a runtime frame or a UI mockup. Preserve the V9 eye
silhouettes, eye pair spacing, single primary highlights, small sparkles and
nose exactly.

Each source is a coordinated special expression. The brows, mouth and cheeks
must make the state legible before the accent is seen. A tiny detached accent
then reinforces the action: Menu uses three thinking dots, Recording uses two
symmetric listening ripples, and Charging uses one two-part breathing arc. The
accent is not a UI/status widget and cannot replace the face. Do not add text,
UI, buttons, battery, plug, lightning, microphone, waveform, menu icon,
question, exclamation, heart or star.

Every visible mark must be separable as a component and fit in a 200x200
export-safe face area. The source must support entry, one bounded in-state
motion and a causal exit through components only.
