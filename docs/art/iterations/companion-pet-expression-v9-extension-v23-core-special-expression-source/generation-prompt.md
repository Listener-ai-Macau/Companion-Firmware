# V23 Core Special Expression Source Prompt

Use only the locked V9 reference image recorded in `generation-request.json`.
Generate one clean monochrome source pose at a time on a pure white background.
The result is source art for component extraction, not a runtime frame or a UI
mockup. Preserve the V9 eye silhouettes, eye pair spacing, single primary
highlights, small sparkles and nose exactly. Do not add text, a UI panel,
buttons, battery, lightning, microphone or menu icon. Do not change the eye
shape or make a new character.

For `menu_active`, show quiet thoughtful focus through brows, mouth and a small
separable three-dot thinking accent above the face. For `recording_active`, show
calm attention through brows and mouth, with optional small symmetric listening
ripples outside the cheeks. For `charging_active`, show a restful replenishing
emotion through relaxed brows, a content mouth and a tiny separable breathing
accent above the face; do not use a battery or lightning symbol.

Every visible mark must be separable as a component and fit in a 200x200
export-safe face area. The source must support entry, one bounded in-state
motion and a causal exit through components only.
