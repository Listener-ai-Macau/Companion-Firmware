# V24 Glance-Readable Special Expression Source Prompt

Use only the locked V9 reference image recorded in
`generation-request-v1-glance-readable.json`. Generate one clean monochrome
source pose at a time on a pure white background. The result is source art for
component extraction, not a runtime frame, a UI mockup or an animation sheet.

Keep the V9 open-eye silhouette, black pupil fills, one primary white highlight
and one small white sparkle per eye, eye-pair spacing, eye baseline and nose
anchor exactly. Do not make a new eye design or a face outline.

This must be read at one glance at native 200x200 without labels: Menu is
purposeful browse/select attention, Recording is clear active listening or
responding, and Charging is obvious replenishing restful relief. Each meaning
must first come from the coordinated brows, mouth and cheeks. Use the secondary
accent only to reinforce that already readable facial action: three compact
step dots for Menu, paired listening arcs for Recording, or two rounded upward
breathing marks for Charging.

Do not add text, a caption, UI, buttons, a menu icon, microphone, waveform,
battery, plug, lightning, question, exclamation, heart, star, colour, shadow,
screen border or a whole-face card. Every black mark must be a detachable
component and fit in a 200x200 export-safe face area. The pose must support a
component-only entry, one bounded in-state motion and a causal exit.
