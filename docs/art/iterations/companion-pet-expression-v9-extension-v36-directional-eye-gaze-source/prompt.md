# V36 Directional Eye-Gaze Source Prompt

Use the supplied locked V9 Companion face image as the only reference. Generate
one clean source sheet containing four square face cells in this exact order:
Daily left, Daily right, Daily up, Daily down. Each cell must preserve the
same V9 character identity and 200x200 black-and-white e-paper composition:
white background; the same star, brows, black open-eye outer silhouettes, eye
positions, cheeks, nose and mouth. Do not add text, labels, borders, color,
grey, shading, texture, accessories, or a new face expression.

Only alter the white internal reflection geometry inside each existing black eye
silhouette. Make the four gaze directions immediately readable at native 200x200:
for left, the large light and its smaller sparkle are visibly biased toward
image-left in both eyes; for right, mirror them toward image-right; for up,
both lights sit clearly above the eye midpoint; for down, both lights sit
clearly below the eye midpoint. Keep a large light plus a smaller companion
sparkle in every eye, with enough separation to read as one directed gaze group.
The outer black eye shape, its size and its placement must remain the same as
the V9 reference. This is a source-art sheet for later component extraction,
not a runtime animation or a replacement for the locked V9 static frame.
