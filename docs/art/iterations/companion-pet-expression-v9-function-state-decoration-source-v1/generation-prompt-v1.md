# Function-State Decoration Source V1

Use only the attached locked V9 reference image. Produce one clean monochrome source sheet containing nine unframed floating-face cells in a 3 by 3 arrangement on pure white, with no captions, panel borders or grid lines. Each cell must remain easy to crop as a native-200-compatible source.

Keep exactly the same cute V9 character identity in every cell: no head, body, ears, hair, frame or card; two black upright oval eyes with the same scale, spacing and baseline; exactly one oval white highlight and one diamond white sparkle in each eye; fixed small nose and cheek dots. Do not invent a different eye shape. Use only crisp black and pure white pixels with no color, gray, gradients, shadows or antialiasing.

Top row, Menu sequence: attentive neutral face, a compact hollow two-by-two navigation grid above the brows, and one tiny filled selection dot moving upper-left to upper-right to lower-right. Keep the grid small and separate from the face. No text, list rows, cursor arrow, screen card, crown or hair ornament.

Middle row, Upgrade sequence: calm hopeful face, one thin hollow upward arrow above the brows and two tiny separated progress ticks below it. The arrow rises from low to middle to high; the second tick arrives only in the final cell. No text, battery, download tray, wireless signal, large filled arrow or full UI panel.

Bottom row, Error sequence: gentle worried face using the same open V9 eye silhouettes, softly inward brows and one small worried downward mouth. Add a small hollow rounded caution diamond above the brows with one compact centre dot. It settles slightly upward from the first to second cell and holds. Do not use a huge exclamation mark, angry eyes, tears, skull, red color, warning text or a UI panel.

Every state mark and every brow/mouth variation must be clean, minimal and separately extractable as a component. This is source art for a component Rig, not a sequence of runtime whole-face stickers.
