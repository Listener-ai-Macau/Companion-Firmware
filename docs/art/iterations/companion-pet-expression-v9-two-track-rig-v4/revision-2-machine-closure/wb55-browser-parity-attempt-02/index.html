表情与状态总览

每张图都是同一套 200x200 组件计划的真实帧；功能状态只叠加小饰件，不替换脸。

日常平静

默认日常脸，眼神轻动后回到正中。

亲近温暖

互动记忆较高时的温和回应。

好奇提问

眼神和眉毛先带动，再出现表情自有问号。

警觉提醒

眉眼先进入提醒，再出现表情自有感叹号。

活泼玩心

高光先活跃，随后回到轻快保持。

困倦入睡

困眼、眉和嘴依次进入，只有 ZZZ 轻轻上浮。

开心雀跃

抬眉、开口笑和高腮点形成清楚的开心反应。

害羞轻笑

收拢的眉、贴近嘴角的腮点和小笑意表达害羞。

安静思考

一高一低眉与偏位思考嘴带出安静停顿。

认真专注

低而圆的收拢眉与短横嘴表达稳定专注。

录音输入中

日常脸旁边播放输入麦克风波纹，绝不覆盖脸。

录音输入中（温暖脸）

同一输入小饰件可与独立温暖表情同时存在。

无线机座充电

日常脸下方显示机座、接触垫和上升能量刻度，不替换脸。

升级进行中

活泼脸上叠加独立上行进度装饰。

错误提醒

平静脸上叠加独立紧凑警示装饰。

进入菜单提示

仅短暂显示；随后组件 Rig 完全撤出，菜单独占屏幕。
