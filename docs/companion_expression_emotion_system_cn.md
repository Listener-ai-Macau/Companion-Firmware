# Companion V9 表情状态系统

本文是 V42 候选的上层状态逻辑说明，不是屏驱动、刷新策略或实体屏验收。所有候选资源保持 inactive。

## 输入与优先级

1. `functional_event` 只选择功能小装饰轨道。它不能选择、替换或修改眼睛、眉毛、鼻子、嘴巴和腮点。
2. 表情轨道按 `emotion` 选择脸的语义：平静、温暖、好奇、警觉、活泼或困倦。
3. `attention` 在同一张脸内选择稳定的视线终点：正中、左、右、上、下。日常视线只移动已登记的高光和星光组件，不改变 V9 眼型。
4. `energy` 只在已登记的轻微高度范围内调节节奏或姿态；`interaction_memory` 只在确定性规则下影响亲近/好奇等日常选择。相同输入必得相同计划，不做随机抽样。
5. 菜单是唯一例外：进入时可以显示一次不超过 500ms 的 `menu_entry_notice`，最后一帧后两条 Rig 轨道完全撤出，菜单 UI 独占屏幕。

## 编舞与转换

- 同一状态不是换整脸贴图。它是从外部 NOR 中的登记掩码按固定锚点、合法偏移、稳定 z 顺序合成 200x200 1bpp 帧。
- 微动作遵守“眼高光/星光先动，眉毛与下半脸响应，目标保持，高光回落”的因果顺序。日常可见保持不少于 750ms。
- 情绪变化复用已接受 V22 的十条有向桥。桥的每一步都可重放，且浏览器与 WB55 上层使用同一组件计划。
- 功能小装饰有独立时序，可与平静或温暖等表情同时出现；缺少合法源组件的功能状态必须 fail-closed，不能借用日常脸伪装完成。
- V42 新增开心雀跃、害羞轻笑、安静思考、认真专注四种脸部语义。它们只替换来源可追溯的眉、嘴、腮组件，继续复用固定 V9 开眼、主高光、小星光和鼻子；不是新眼型，也不是整脸贴图。
- V42 的录音只播放右侧安全区的输入麦克风波纹，充电只播放脸下方的无线机座能量波。两者均与脸逐像素零重叠，且不能反向选择或改写 `emotion`。
- V42 睡眠只从困眼、困眉、嘴和三个独立 `ZZZ` 组件组成。月亮、月牙、云和旧的月亮加 Z 组合掩码均不在 V42 分数中。

## 五向眼神

V41/V42 使用 V9 已登记的左右主高光和小星光组件。正中、左、右、上、下仍保留为内部机器证明；在 owner-visible 的 200x200 表情小框内，触摸坐标会沿 X/Y 轴连续映射到这些组件的合法 offset 范围，形成“摸哪里、看哪里”的离散像素级视线，而不是只选择五个方向。鼻子组件 ID 4 永远在 `[0,0]`。这些变化被布局门禁、host 测试、浏览器 200x200 组件渲染和 WB55 像素回放共同验证。它们是视觉注意力，不是新的眼型或新的完整脸；触摸不会改变当前情绪、眉、嘴或鼻子。

## 验收边界

机器门禁只证明组件来源、状态选择、时序、像素等价和 fail-closed 边界。只有这些全部通过后，才请人查看中文总览与所选编舞的可读性；人工失败会保留候选证据并回到源图或上层编舞修复，不能改写锁定 V9 基线。
